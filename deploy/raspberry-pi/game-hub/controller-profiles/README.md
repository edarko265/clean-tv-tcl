# Controller profiles

RetroArch's bundled autoconfig database should be the first choice. After pairing a controller directly to the TV,
use **Settings → Input → RetroPad Binds → Port 1 Controls**, verify every physical button, then save a controller
profile or per-core remap here as a private backup. Controller Bluetooth addresses and unique device identifiers
must not be committed.

Recommended starting layouts:

| Controller | Confirm/Cancel | Menu hotkey suggestion |
|---|---|---|
| Xbox-style | A / B | Hold Select, press Start |
| PlayStation-style | Cross / Circle | Hold Share, press Options |
| Switch Pro-style | A / B as labelled | Hold Minus, press Plus |

Do not enable a global quit hotkey until it has been physically tested; a bad mapping can make games impossible to
control. Keep the TV remote's Home button as the universal escape route.
