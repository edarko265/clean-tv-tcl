# Support

## Where to ask

- Use [GitHub Issues](https://github.com/edarko265/clean-tv-tcl/issues) for reproducible bugs and scoped feature proposals.
- Use [GitHub Discussions](https://github.com/edarko265/clean-tv-tcl/discussions) for setup questions and ideas when Discussions is enabled.
- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).

Before opening an issue, search existing reports and read [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md).

## Include

- TV brand and exact model;
- Android TV version and firmware build;
- the commit or release used;
- the command that failed and sanitized output;
- expected and actual behavior;
- whether restore was attempted and its result.

Never include IP addresses, Wi-Fi names, MAC addresses, serial numbers, Android IDs, account emails, API keys, ADB keys, backups, or unredacted Settings screenshots.

## Scope

Best-effort support covers the repository's documented tools, launcher, themes, and tested TCL configurations. It does not cover unofficial APK mirrors, piracy/indexer configuration, rooted devices, modified firmware, bypassing platform security, or devices administered without authorization.

This is a community project with no guaranteed response time or warranty. If the TV is the household's only display, keep the stock launcher enabled until the replacement has survived a reboot and restore has been verified.
